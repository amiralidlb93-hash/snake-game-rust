# بازی مار با Rust

یک بازی مار ترمینالی با کنترل صفحه‌کلید، نوشته‌شده با Rust و `crossterm`.

## اجرا

Rust و Cargo را نصب کنید، سپس از پوشهٔ پروژه اجرا کنید:

```bash
cargo run --release
```

## کنترل‌ها

- حرکت: کلیدهای جهت‌دار یا `W A S D`
- مکث/ادامه: `P` یا فاصله
- شروع دوباره: `R`
- خروج: `Q` یا `Esc`

با خوردن میوه، امتیاز افزایش می‌یابد و سرعت مار بیشتر می‌شود. بعد از برخورد، `R` بازی را از نو شروع می‌کند.
